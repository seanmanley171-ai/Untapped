# Untapped

Personal potential discovery platform

UNTAPPED helps you find value in what you already have. List the things you have,
the skills you can do, and what you want — plain rules (no AI) match you to ideas
that fit, explain why, show what you're missing, and give you the first steps.
Turn any idea into a project and track your steps.

- Free-first. No account. Your lists stay on your own device.
- 29 starter ideas, matched on resources, abilities, goal, hours, and budget.
- Over-budget and over-time ideas are flagged, never hidden. No made-up earnings.

Open `index.html` or the GitHub Pages site for this repo to use it.
